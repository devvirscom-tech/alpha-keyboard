ALPHA KEYBOARD 2.0 — نسخة مشروع أولية

مهم:
- لا يوجد مفتاح API ضمن الملفات.
- المفتاح الذي أرسلته في المحادثة يجب إلغاؤه/تدويره من Google AI Studio، لأنه أصبح مكشوفاً.
- لا ترفع مفاتيح API إلى GitHub.
- اطلب من ولي أمرك إدارة حساب الخدمة ومفتاحها وأي إعداد فوترة أو شروط عمرية.

المشروع:
- Android: لوحة إدراج أكواد محفوظة + شاشة حافظة + واجهة طلبات AI.
- Worker: وسيط API يحفظ مفتاح Gemini على الخادم كمتغير Secret.
- لا يوجد إرسال تلقائي لرسائل WhatsApp أو Discord. المستخدم يراجع الرد ويضغط إرسال بنفسه.

بناء Android من الهاتف:
1) ارفع مجلد المشروع إلى مستودع GitHub.
2) يمكن استخدام GitHub Actions لبناء APK؛ أضف workflow مناسباً أو استخدم Android Studio على جهاز بناء.
3) افتح worker في Cloudflare Workers، وانشر worker/src/index.js.
4) عيّن Secret باسم GEMINI_API_KEY من لوحة Cloudflare، ولا تضع قيمته في ملفات المشروع.
5) ضع رابط Worker المنشور (HTTPS وينتهي بعنوان الخادم فقط) في إعدادات تطبيق ALPHA.

تنبيه حول الحصة المجانية:
الحصص والنماذج المتاحة تتغير حسب الحساب والمنطقة وسياسات المزوّد. تحقق من لوحة Google قبل الاستخدام.

حدود النسخة:
- الحافظة تحفظ النصوص في SQLite محلياً.
- التطبيق الذي تستهدفه قد يرفض إدراج نص شديد الطول.
- لوحة المفاتيح حالياً مخصصة لإدراج الأكواد المحفوظة؛ الردود AI تُولد في شاشة التطبيق ثم تنسخها.
- لا تقرأ هذه اللوحة محادثات WhatsApp أو Discord تلقائياً، ولا تتجاوز خصوصية التطبيقات.
- حماية R8/توقيع APK ليست حماية مطلقة. سر API يبقى على الخادم.
